# v3（原稿から直接つくる2Dモデル）

- 元データ：`original/七瀬真冬さん立ち絵差分.psd`（描いた本人からもらった原稿。手を加えない）
- 作り方：`ai/venv/Scripts/python.exe tools/build_v3.py`（倍率を変えるときは引数で。既定 0.6）
- 出力：`v3/dist/mafuyu_v3_free.psd`（1200×2494、Cubism FREE の 2048 テクスチャ1枚に収まる）、`v3/parts/*.png`（原寸のレイヤー確認用）

## 方針
- 顔を横に向ける3D的な動きはしない。体全体の揺れ・傾き、呼吸、ツインテールとアホ毛の物理、まばたき、口パク、表情と腕ポーズの切り替えで動かす
- 髪・顔・体は原稿の1枚をそのまま使う（切り抜かない）。v2 の手作業パーツは使わない
- 冬服・黒靴下だけ。夏服・白靴下は後で別モデルにする

## レイヤー（下から）
| フォルダ | 中身 |
|---|---|
| 後ろ | ツインテール L / R（L・R は画面から見た左右） |
| 体 | 脚、スカート、上半身（原稿の1枚を y=2000・2480 で3つに切ったもの）、校章 |
| 腕 R | 下ろし、手を振る |
| 腕 L | スクバ持ち、下ろし、ピース、手を口元（スクバの紐は腕側にある） |
| 目 | 原稿の表情から目・眉・頬・鼻を取り出したもの 12種（下の表） |
| 口 | 原稿の表情から口だけ取り出したもの 20種（番号は原稿の表情番号） |
| 漫符 | 原稿のアクセサリー 1〜14（13 のハートと 14 のキラキラは3つずつに分けた） |
| アホ毛 | 0〜7 |
| 前 | 前髪透け（目の上にかかる前髪の毛先） |

目：01 通常、02 笑顔、05 閉じ、07 白丸、08 ウィンク、10 ぎゅっ（><）、12 ジト目、13 黒目、14 ぐるぐる、18 泣き、24 ハート、25 キラキラ

口パクに使える口：01 閉じ（にっこり）→ 22 小さく開く → 06 「お」 → 02 大きく開く

漫符：01 怒り、02 はてな、03 照れ（頬）、04 汗（あご）、05 青ざめ、06 もやもや、07 音符、08 汗、09 考え中、10 汗（頭）、11 照れ汗、12 汗、13 ハート、14 キラキラ

## Cubism（`Cubism/mafuyu_v3.cmo3`）
PSD を新しいモデルとして読み込み（「グループを結合」は外す）、骨組みは API で作る。
- `v3/rig/gen_keys.py`：一括処理（`batch_*.json`）を作る。パラメータ整理、目・口・漫符・アホ毛・腕の切り替えキー、デフォーマの親子付け、揺れのキー
- `v3/rig/run_batches.py`：一括処理を Cubism に流す（`uvx --from cubism-mcp python v3/rig/run_batches.py batch_2_eyes.json ...`）
- 回転デフォーマ7つ（Rot_Body / Rot_Breath / Rot_TailL / Rot_TailR / Rot_ArmL / Rot_ArmR / Rot_Ahoge）は、中心の位置だけ手で合わせる（`v3/rig/回転の中心_v3.png`）。空の状態で作って位置を合わせてから、`batch_7_tree` で中身を付ける
- メッシュの自動生成は不要（曲げずに回転と切り替えだけで動かすため）

切り替えパラメータ：目の種類 0〜10、口の種類 0〜16（0 は口パク）、漫符 0〜13、照れ、アホ毛の形 0〜7、左腕 0〜3、右腕 0〜1。番号の中身は `gen_keys.py` と `tools/install_model.py` の EXPRESSIONS を参照。

## 書き出しと VTube Studio
- テクスチャアトラス 2048×2048 を1枚。moc3 を `v3/export` に書き出す（名前はそのままでよい）
- `python tools/install_model.py --v3`：名前を mafuyu.* に揃え、物理演算（アホ毛・ツインテール・腕）と表情20個を作り、VTS の `mafuyu_v3` フォルダへコピーする
