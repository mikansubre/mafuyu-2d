# 手作業の切り抜き

元イラスト `4_4.png`（2000×4156）から、線画に沿ってパーツを切り抜いたものを置く場所。

- キャンバスサイズと位置はそのまま（元の絵とぴったり重なる状態）で保存する
- PSDの場合はレイヤー名をパーツ名にする（PNGの場合はファイル名をパーツ名にする）
- 切り抜くだけでよい。隠れていた部分の塗り足しは `ai/build_psd.py` が行う

| パーツ名 | 内容 |
|---|---|
| 胴体 | 身頃と襟（襟の後ろの首の両脇まで）。腕・首・髪は含めない |
| 腕 L / 腕 R | 袖と手（画面で見て左・右） |
| 肩の髪 L / 肩の髪 R | 肩や袖の上にかかっている髪 |

まずは「胴体」だけ作り、自動の切り抜きと比べて仕上がりを確認する。
