# v2（正式版のパーツ）

2026-10-06 から、手作業で切り抜いたこのv2のパーツを正式版として使う。
v1（`ai/build_psd.py` で自動生成したパーツ、`dist/`、`parts/`、`Cubism/mafuyu_live2d_parts_free.cmo3`、`export/`）は前のバージョンとして、そのまま残している。

| ファイル | 内容 |
|---|---|
| `mafuyu_live2d_parts_v2.psd` | 元データ（2000×4156）。直すときはこれを編集する |
| `dist/mafuyu_v2_free.psd` | Cubism FREEで読み込む用（0.65倍、テクスチャ2048に収まるサイズ） |
| `parts/*.png` | 各レイヤーの確認用画像（元のサイズ） |

元データを直したら、次のコマンドで作り直す：

```
ai/venv/Scripts/python.exe tools/build_v2.py
```

- 「元絵（参照用）」レイヤーは書き出さない
- フォルダ構成・重なり順・非表示（閉じ目・笑い目・口 開き）は元データのまま
- v1にあって無いもの：眉、肩の髪、口 閉じ（閉じた口は顔に含まれている）
- v1に無くて新しくあるもの：スカーフ、襟の裏、リボンの垂れ
